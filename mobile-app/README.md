# Ski Info — app móvil (fase 2)

Pendiente de empezar. Consumirá el SQLite generado por `data-pipeline/` para
mostrar fichas de estación sin conexión: desnivel, km de pista por dificultad,
remontes, pendiente real y esquí nocturno.

Se documentará aquí la elección de framework (Flutter / React Native) y la
estructura del proyecto cuando arranque esta fase.
